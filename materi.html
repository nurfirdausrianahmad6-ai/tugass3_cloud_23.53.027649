MATERI PEMBELAJARAN

Komputasi Awan

Mengenal teknologi Cloud Computing dan penerapannya dalam kehidupan sehari-hari.

Pelajari Materi

1. Pengertian Komputasi Awan

Komputasi awan atau Cloud Computing adalah teknologi yang menyediakan sumber daya komputasi melalui jaringan internet. Sumber daya tersebut dapat berupa penyimpanan data, server, database, jaringan, dan perangkat lunak.

Dengan teknologi ini, pengguna tidak harus memiliki atau mengelola seluruh perangkat keras dan perangkat lunak sendiri. Pengguna cukup terhubung ke internet untuk mengakses layanan sesuai kebutuhan.

2. Contoh Cloud Computing

📁
Google Drive

Menyimpan dan berbagi file secara online.

✉️
Gmail

Mengirim dan menerima email melalui internet.

🎬
Netflix

Menonton film dan video secara streaming.

3. Cara Kerja Cloud Computing

Cloud Computing bekerja dengan menghubungkan pengguna ke server atau pusat data melalui jaringan internet.

💻

Pengguna

Mengakses layanan menggunakan laptop atau smartphone.

🌐

Internet

Menghubungkan perangkat pengguna dengan layanan cloud.

☁️

Server Cloud

Memproses permintaan dan menyimpan data pengguna.

4. Model Layanan Cloud Computing

SaaS
Software as a Service

Layanan perangkat lunak yang dapat digunakan secara langsung melalui internet tanpa harus mengelola server sendiri.

Contoh:

Google Docs, Gmail, Microsoft 365.

PaaS
Platform as a Service

Platform untuk mengembangkan, menguji, dan menjalankan aplikasi tanpa harus mengelola infrastruktur server secara langsung.

Contoh:

Google App Engine, Heroku, Azure App Service.

IaaS
Infrastructure as a Service

Layanan infrastruktur teknologi informasi seperti server virtual, penyimpanan, dan jaringan sesuai kebutuhan.

Contoh:

Amazon EC2, Google Compute Engine, Azure VM.

5. Manfaat Komputasi Awan

💰 Menghemat Biaya

Mengurangi kebutuhan membeli dan merawat server sendiri.

🌍 Akses Fleksibel

Data dan aplikasi dapat diakses dari berbagai lokasi melalui internet.

📈 Mudah Dikembangkan

Kapasitas penyimpanan dan komputasi dapat disesuaikan dengan kebutuhan.

🤝 Memudahkan Kolaborasi

Beberapa pengguna dapat bekerja pada dokumen yang sama secara online.

6. Risiko Komputasi Awan

Data dapat berisiko jika akun diretas atau pengaturan keamanan tidak tepat.

Akses layanan dapat terganggu ketika koneksi internet bermasalah.

Server atau penyedia layanan dapat mengalami gangguan sehingga layanan sementara tidak tersedia.

Pengguna perlu memahami bagaimana penyedia layanan mengelola dan melindungi data pribadi.

Kesimpulan

Komputasi awan merupakan teknologi yang memberikan kemudahan dalam mengakses penyimpanan, aplikasi, dan sumber daya komputer melalui internet. Teknologi ini memiliki tiga model layanan utama, yaitu SaaS, PaaS, dan IaaS. Selain memberikan manfaat berupa efisiensi biaya, fleksibilitas, dan kemudahan kolaborasi, pengguna juga harus memperhatikan keamanan data, privasi, serta ketergantungan terhadap internet.
